# 楠小遊覽車座位表

高雄市楠梓國小 校外教學遊覽車座位安排工具。

**使用網址：https://ntpsbing.github.io/bus-seats/**

## 功能
- 匯入學生名單（從 Excel／Google 試算表複製貼上，或上傳 Excel、CSV）
- 拖拉調整座位（手機、平板按住再拖，或點名字再點座位）
- 一鍵安排：依座號、同性兩人同坐、男女交錯、隨機；老師坐前排、暈車優先
- 鎖定座位、復原／重做、多台車、手機點名模式
- 每台車一張 A4 列印（黑白／彩色）、下載成 PNG 圖片、匯出 Excel 名單

## 個資與資安
- 這是純前端網頁，**名單不會上傳到任何伺服器**，只存在使用者自己的瀏覽器（localStorage）與自己下載的 .json 存檔。
- 學生姓名一律以 textContent 顯示，不會被當成程式執行。

## 給接手的人
- 全部程式都在 `index.html` 一個檔案，有中文註解。
- 車型在程式裡的 `PRESETS`（常用車型）與 `buildLayout()`（通用產生器）。目前有 43 人座、36 人座 2+1 豪華車（左單人 12 排、右雙人 12 排）、45 人座；老師也可在「車輛資料 → 車型 → 自訂車型」自己填左右排數、每排人數、後門位置、後排人數。
- 更新方式：把新的 `index.html` 上傳覆蓋到這個 repo，約 1 分鐘後網址就會更新。
- 原始檔與使用說明同步存放在學校雲端：`115_教研組/30_遊覽車座位安排`。
